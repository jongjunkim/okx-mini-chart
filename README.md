# OKX Mini Chart

모니터 한쪽에 띄워 두는 작은 macOS 차트 앱입니다. OKX 공개 시세 API에서 봉과 거래량을 받아 실시간으로 그립니다.

- 여러 종목을 한 창에 위아래로 쌓아 봅니다(최대 6칸). 맨 아래 `＋ 종목 추가`를 누르면 창이 아래로 늘어나며 새 칸이 생기고, 칸 오른쪽 위 `×`로 닫으면(5초 안에 되돌리기 가능) 그만큼 줄어듭니다. `⌃`로 접으면 시세 한 줄과 작은 추이선만 남습니다. 칸 사이 막대를 끌어 높이를 나누고, 두 번 클릭하면 똑같이 나눕니다. 칸 구성은 저장됩니다.
- 칸마다 종목과 봉 간격(1m·5m·15m·1h·4h·1d 중 하나)을 따로 고릅니다.
- 일봉은 OKX 기본값(`1D`, UTC+8 기준)이라 한국 시간 01시에 시작합니다. 4시간봉은 01·05·09·13·17·21시에 끊깁니다.
- 봉마다 거래량 막대가 붙고, 마우스를 올리면 시가·고가·저가·종가·거래량이 나옵니다.
- 지표: 이동평균 4개(각각 SMA/EMA/VWMA·기간·선 색 선택)와 볼린저밴드(기간·배수·선 색), RSI(기간·선 색, Wilder 방식)를 `지표` 버튼에서 켜고 끕니다. RSI는 차트 아래쪽 띠에 70·50·30 기준선과 함께 그려지고, 켜면 봉·거래량이 위로 조금 줄어듭니다. 설정은 모든 종목·간격에 함께 적용됩니다. 과거 봉을 간격마다 1200개까지 미리 받아 계산하므로 값이 OKX·TradingView 와 같고, 화면 왼쪽 끝까지 선이 이어집니다.
- 가격 알림: 차트를 우클릭해 `가격 알림`을 고르면 우클릭한 가격이 채워진 입력 창이 열립니다. 원하는 가격으로 고쳐 Enter(또는 `알림 걸기`)를 누르면 그 가격에 보라색 점선이 생기고, 현재가보다 위면 상향 돌파·아래면 하향 이탈로 걸립니다. 체결가(OKX `tickers`)가 그 가격에 닿는 순간 맥 알림 배너와 소리로 한 번 알려 주고 선은 지워집니다. 선 라벨에 현재가까지 거리(%)가 나오고, 선은 위아래로 끌어 옮기고(현재가를 넘기면 방향도 바뀜) `×`나 우클릭 `이 가격 알림 지우기`로 지웁니다. 칸에 띄운 종목 그대로(현물은 현물, 무기한은 무기한 가격) 보고, 그 종목을 칸에서 닫아도 계속 감시합니다. `알림` 패널 맨 위에 걸린 알림 목록이 있고, 누르면 그 종목을 칸에 띄웁니다. 아래 봉 마감 알림의 `켜기`와 상관없이 늘 감시하고, 알림 방법(배너·소리)은 같이 씁니다. 앱이 꺼져 있던 동안 닿았다가 되돌아온 건 못 잡고, 다시 켰을 때 이미 넘어가 있으면 그때 울립니다.
- 봉 마감 알림(`알림`): 지표에서 켠 이동평균이 정배열(짧은 선이 위)이 되고 모든 선이 N봉 전보다 높아지는 순간 맥 알림 배너와 소리로 알려 줍니다. 봉이 마감될 때 판정하고, 조건이 새로 맞은 순간 한 번만 울립니다. 봉 간격(1m·5m·15m·1h)과 대상(칸에 띄운 종목, 칸에 없어도 보는 감시 목록)을 고르고, 울린 봉에는 차트에 `정배열` 표시가 붙습니다. 알림을 누르면 그 종목을 칸에 띄웁니다. 앱이 켜져 있을 때만 동작합니다.
- 돌파 채널(`지표`): 직전 N봉 고가(실선, 기본 20)와 직전 M봉 저가(점선, 기본 10)를 계단선으로 그립니다. 종가가 고가선을 넘은 봉에 `돌파`, 그 뒤 저가선 아래로 마감한 봉에 `청산` 표시가 붙습니다(마감된 봉만). 일봉 20·10 으로 검증한 규칙입니다: Binance 일봉 2020~2026, 수수료 0.1% 기준 승률 35~48%, 이긴 거래 평균이 진 거래의 3~7배, 처음 보는 15코인에서 거래당 +11%(무작위 진입 +4%). 5분·15분봉의 거래량·연속봉·정배열 조합은 같은 방식으로 검증해 우위가 없었습니다.
- 일봉 돌파 알림(`알림`): 일봉이 마감될 때(한국 시간 01시) 돌파·청산이 새로 나오면 알려 줍니다. 돌파 알림에는 청산 기준(M일 저가)과 그까지 거리(손절 폭 %)가 같이 옵니다. 대상 종목·알림 방법은 정배열 알림과 같이 씁니다.
- 그리기: `수평`(지지·저항선)은 한 번 클릭, `추세`는 두 점을 클릭합니다. 추세선은 오른쪽으로 연장됩니다.
- 가격 범위(`범위`): 두 점을 클릭하면 가격 차이·변동률·봉 수를 보여 줍니다.
- 롱·숏 포지션(`롱`·`숏`): 진입가를 한 번 클릭하면 목표(초록)·손절(빨강) 구간과 손익비가 생깁니다. 처음엔 손익비 2로 놓이고, 목표·손절선을 위아래로, 오른쪽 끝을 좌우로, 몸통을 끌어 통째로 옮깁니다. 손절선은 진입가를 넘어가지 않습니다.
- 수정·삭제: 그린 선·상자를 클릭하면 선택됩니다. 수평선은 위아래로 끌어 옮기고, 추세선은 끝점을 끌면 기울기가, 선을 끌면 위치가 바뀝니다. 선택한 채로 Backspace(또는 Delete)를 누르면 지워지고, Esc나 빈 곳 클릭으로 선택을 풉니다.
- 되돌리기·잠금: 그리기·옮기기·지우기·모두 지우기는 ⌘Z(또는 `↶`)로 되돌리고 ⌘⇧Z(또는 `↷`)로 다시 실행합니다. 최근 100번까지이고 앱을 다시 켜면 비워집니다. 자물쇠 버튼을 켜면 그린 선이 클릭·끌기로 선택되거나 움직이지 않습니다. 잠근 채로 새 선은 그릴 수 있고, 잠금 상태는 저장됩니다.
- 리플레이(`리플레이`): 누른 뒤 차트에서 시작할 봉을 클릭하면 그 봉까지만 보이고 뒤는 가려집니다. 화면은 클릭한 그대로 멈춰 있고(가로·세로 모두), 재생하면 빈 오른쪽을 채우다가 끝에 닿으면 한 봉씩 밀립니다. 차트를 끌거나 휠을 돌리면 가격축이 다시 자동으로 맞춰집니다. 칸 머리줄 아래 막대에서 `▶ 재생`(초당 1·3·10봉), `한 봉 ▷`(Shift+→), 재생·멈춤(Space)으로 앞으로 넘기고, 날짜칸에 시각을 넣으면 그 시점부터 다시 시작합니다(OKX 에 봉이 있는 2018~2019년까지). 1m~1d 모두 되고, 리플레이 중 간격을 바꿔도 시각은 그대로라 그 시각까지 마감된 봉만 나옵니다. 이동평균·RSI 도 보이는 봉으로만 계산하므로 미래 값이 섞이지 않습니다. 칸마다 따로 돌아서 한 칸은 실시간, 다른 칸은 리플레이로 볼 수 있습니다. `끝내기`(또는 선택·패널이 없을 때 Esc)로 실시간으로 돌아갑니다.
- 리플레이 백테스트 매매: 리플레이 막대 아래 `백테스트` 줄에서 시드(기본 10,000 USD)와 레버리지(1~100x)를 고르고 `시작`을 누릅니다. 재생하면서 `매수`(B)·`매도`(S)·`정리`(X, 방향과 상관없이 전량 닫기)를 누르면 **다음 봉 시가**에 체결됩니다(지금 보이는 봉 종가에 사면 미래를 아는 셈이라). 한 번에 가용 잔고의 10·25·50·100%를 증거금으로 쓰고, 같은 방향은 추가 진입, 반대 버튼은 닫기입니다. 격리 증거금으로 계산해 청산가(유지증거금률 0.4%)에 닿으면 그 포지션 증거금을 모두 잃고, 체결마다 수수료 0.05%를 뗍니다. 자산·수익률·미실현 손익·거래 수·승률이 줄 오른쪽에 나오고(마우스를 올리면 가용 잔고·수수료 누계·최대낙폭), 차트에 진입·청산 화살표가 찍히고, TradingView 포지션 선처럼 진입가에 롱은 빨간 선·숏은 파란 선이 그어지며 선 오른쪽 라벨에 방향·배율·수량과 미실현 손익(USD·증거금 대비 %)이 봉마다 따라 바뀝니다. 강제청산가는 회색 점선입니다. 실시간 가상 거래 계좌와는 따로 굴러갑니다. 리플레이 중 봉 간격을 바꿔도 계좌·포지션·체결 표시가 그대로 이어지고, `끝내기`(또는 종목 변경)나 `초기화`를 누를 때만 결과 창을 띄우고 지웁니다. 결과 창에는 기간(리플레이 시각 기준 며칠·몇 시간), 시드 → 최종 자산과 수익률, 거래 횟수·승률·평균 보유시간, 거래당 평균·최고·최저 손익, 최대낙폭, 수수료 합계가 나오고, 거래마다 방향·배율, 진입·청산 시각과 가격, 보유시간, 손익(USD·증거금 대비 %)이 표로 나옵니다. 끝날 때 들고 있던 포지션은 마지막 종가로 닫았다고 보고 '미청산'으로 따로 적습니다. 미래를 미리 보지 않도록 백테스트 중에는 날짜·시작점을 뒤로 옮길 수 없고, 포지션이나 대기 주문이 있으면 앞으로 건너뛸 수도 없습니다. 굵은 간격으로 바꾼 직후처럼 다음 봉 시가가 주문 시각보다 앞서면 그 봉 종가에 체결합니다.
- 가상 거래(`거래`): 실제 OKX 시세로 체결만 앱 안에서 계산하는 연습용 매매입니다. 실제 주문은 나가지 않습니다. 차트 우클릭 주문, 진입가·TP·SL·주문선, 위쪽 가상 잔고는 `거래`를 누르지 않아도 항상 쓸 수 있습니다. `거래`를 누르면 창이 오른쪽(주문 패널)과 아래(포지션·미체결·체결 내역·자산)로 늘어납니다. 주문 패널 머리줄의 `›`(또는 ⌘])로 패널을 오른쪽 끝 띠로 접으면 창이 그만큼 줄어들고, 띠를 누르면 다시 펼쳐집니다. 접힌 상태는 저장됩니다. 가상 잔고를 누르면 자산 탭이 열립니다.
  - 시드머니: `자산` 탭에서 USDT를 충전합니다. 충전 누계와 실현 손익(수수료·펀딩비 포함)을 따로 보여 주고, `계정 초기화`는 두 번 눌러야 됩니다.
  - 주문: 클릭한 칸의 종목으로 지정가·시장가·스톱(트리거에 닿으면 시장가)을 넣습니다. 현물 칸(BTC-USDT)에서는 같은 코인의 무기한(BTC-USDT-SWAP)으로 주문합니다. 수량은 코인 또는 USDT로 넣고, 25~100% 버튼은 주문 가능 금액 기준입니다. TP·SL을 주문에 붙일 수 있습니다.
  - 레버리지·마진: 종목마다 1배~OKX 최대 배율, 격리·교차를 고릅니다. 포지션이나 미체결 주문이 있는 동안은 바꿀 수 없습니다. 포지션은 종목당 한 방향(OKX 단방향 모드)이라 반대 주문은 먼저 기존 포지션을 닫고, 남는 만큼만 반대 포지션을 엽니다. 금액(증거금·USDT)으로 넣은 반대 주문은 닫는 부분을 기존 포지션의 진입가로 환산하므로, 롱을 증거금 500으로 열었다면 숏 500이 그 롱을 정확히 전부 닫고 숏 700은 롱을 닫은 뒤 남은 200으로 숏을 엽니다. 닫고 남는 양이 최소 주문량보다 작으면 전부 닫습니다.
  - 차트 우클릭: 커서 가격이 현재가보다 아래면 지정가 매수·스톱 매도, 위면 지정가 매도·스톱 매수가 뜹니다. 고르면 그 자리에 주문 창이 열려 넣을 증거금(USDT, 레버리지를 곱한 만큼 삼)이나 코인 수량을 입력하고 Enter 로 주문합니다. 25~100% 버튼은 주문 가능 금액 기준이고, 마지막에 넣은 증거금을 기억합니다. 반대 포지션이 있으면 닫는 수량·새로 여는 수량을 나눠 보여 주고 `포지션 전부 닫기` 버튼이 생깁니다. 포지션이 있으면 그 가격으로 TP/SL 옮기기, 주문선 위에서는 주문 취소, 수평선 그리기도 있습니다.
  - 차트 선: 진입가(손익·ROE)·TP·SL·미체결 주문·청산가를 그립니다. TP·SL·주문선은 위아래로 끌어 고치고 `×`로 지웁니다. 화면 밖이면 위·아래 끝에 표시만 남습니다.
  - 체결 규칙: 시장가는 최근 체결가로 즉시(테이커 0.05%), 지정가는 체결가가 닿으면 그 가격으로(메이커 0.02%, 이미 넘은 가격이면 즉시 테이커), 스톱·TP·SL은 체결가가 닿으면 그 시점 가격으로(테이커). 격리는 마크가격이 청산가에 닿으면 그 증거금을 모두 잃고, 교차는 총자산이 유지증거금(OKX 구간표) 아래로 내려가면 교차 포지션을 모두 닫고 미체결 주문을 취소합니다. 펀딩비는 OKX가 정산한 실제 값으로 주고받습니다.
  - 앱이 꺼져 있던 동안은 다시 켤 때 그 사이 1분봉의 고가·저가로 소급 판정합니다(최대 7일, 같은 봉에서 손절과 목표가 함께 닿으면 손절 먼저, 이때 청산 판정은 마크가격 대신 체결가 봉 기준). 계정은 이 맥에만 저장됩니다.
- 그리기 도구는 위쪽에 하나만 있고, 클릭한 칸의 종목에 그려집니다. 그린 선은 종목별로 저장되어 같은 종목을 보는 다른 칸(다른 봉 간격)에도 같이 보입니다.
- 종목 입력칸에 몇 글자만 치면 현물·무기한 선물 후보가 거래대금 순으로 뜹니다. `sox`를 치면 `SOXL-USDT-SWAP`이 나옵니다.
- `TOP10` 버튼: 24시간 거래대금(USD) 상위 10종목을 전체·현물·무기한으로 나눠 보여 줍니다. 등락률이 함께 나오고, 열어 두면 10초마다(시세는 1분마다) 갱신됩니다. 종목을 누르면 선택한 칸에 띄웁니다. OKX 시세 API 는 24시간 누적 거래량만 주므로 '오늘 0시부터'가 아니라 최근 24시간 기준입니다.
- `캡처` 버튼(또는 ⌘S)으로 차트 칸 하나만 PNG로 찍어 바탕화면(`~/Desktop`)에 저장하고 클립보드에도 복사합니다. 칸이 하나면 바로 찍히고, 여러 개면 마우스를 올린 칸에 빨간 테두리가 생기며 그 칸을 클릭하면 찍힙니다(칸 밖 클릭·Esc는 취소). 창 전체는 보기 → 창 전체 캡처(⌘⇧S)입니다. 옵시디언·노션에 바로 ⌘V로 붙여 넣을 수 있습니다. 파일 이름에 날짜·시각·종목이 들어갑니다.
- 보기 → 항상 위에 표시(⌘T)를 켜면 다른 창 위에 고정됩니다.
- 제목 표시줄 오른쪽 위 슬라이더를 왼쪽으로 끌면 창이 투명해집니다(최대 70% 투명). ⌥⌘- / ⌥⌘= 로 10%씩 조절할 수도 있습니다. 항상 위에 표시와 같이 쓰면 다른 창 위에 반투명하게 띄워 둘 수 있습니다.
- 상승은 빨강, 하락은 파랑이고 시간은 맥 시간대를 따릅니다.

로그인이나 API 키는 쓰지 않습니다. 시세를 읽기만 하고, 가상 거래도 실제 주문을 내지 않습니다.

## 빌드와 설치

macOS 13 이상과 Xcode Command Line Tools(`swiftc`)가 있으면 됩니다.

```sh
./build.sh           # build/OKX Mini Chart.app 생성
./build.sh install   # ~/Applications 에 복사
```

## 구성

| 경로 | 내용 |
|---|---|
| `web/index.html` | 차트 화면 전체. [Lightweight Charts](https://github.com/tradingview/lightweight-charts) 4.2.0을 CDN에서 불러옵니다 |

화면만 고칠 때는 `web/index.html`을 브라우저로 열어 확인한 뒤 `./build.sh install`로 다시 넣으면 됩니다.

## 쓰는 OKX API

- 과거 봉: `GET /api/v5/market/candles` 로 최근 300개, 이어서 `GET /api/v5/market/history-candles` 로 1200개까지 미리 받고, 왼쪽으로 스크롤하면 300개씩 더 받습니다
- 실시간 봉: `wss://ws.okx.com/ws/v5/business` 의 `candle1m`·`5m`·`15m`·`1H`·`4H`·`1D`. 알림 대상 종목·간격도 같은 채널을 구독하고, 마감 봉(`confirm=1`)으로 판정합니다
- 현재가·24시간 등락률: `GET /api/v5/market/ticker` (10초마다)
- 종목 검색: `GET /api/v5/market/tickers` (현물·무기한, 5분 캐시)
- 가격 알림: `wss://ws.okx.com/ws/v5/public` 의 `tickers`(체결가)
- 가상 거래: 계약 정보 `GET /api/v5/public/instruments`, 유지증거금률 `GET /api/v5/public/position-tiers`, 펀딩비 `GET /api/v5/public/funding-rate-history`, 실시간 체결가·마크가격 `wss://ws.okx.com/ws/v5/public` 의 `tickers`·`mark-price`, 꺼져 있던 동안의 판정은 1분봉 `history-candles`
