# OKX Mini Chart

모니터 한쪽에 띄워 두는 작은 macOS 차트 앱입니다. OKX 공개 시세 API에서 봉과 거래량을 받아 실시간으로 그립니다.

- 여러 종목을 한 창에 위아래로 쌓아 봅니다(최대 6칸). 맨 아래 `＋ 종목 추가`를 누르면 창이 아래로 늘어나며 새 칸이 생기고, 칸 오른쪽 위 `×`로 닫으면(5초 안에 되돌리기 가능) 그만큼 줄어듭니다. `⌃`로 접으면 시세 한 줄과 작은 추이선만 남습니다. 칸 사이 막대를 끌어 높이를 나누고, 두 번 클릭하면 똑같이 나눕니다. 칸 구성은 저장됩니다.
- 칸마다 종목과 봉 간격(1m·5m·15m·1h·4h·1d 중 하나)을 따로 고릅니다.
- 일봉은 OKX 기본값(`1D`, UTC+8 기준)이라 한국 시간 01시에 시작합니다. 4시간봉은 01·05·09·13·17·21시에 끊깁니다.
- 봉마다 거래량 막대가 붙고, 마우스를 올리면 시가·고가·저가·종가·거래량이 나옵니다.
- 지표: 이동평균 4개(각각 SMA/EMA/VWMA·기간·선 색 선택)와 볼린저밴드(기간·배수·선 색)를 `지표` 버튼에서 켜고 끕니다. 설정은 모든 종목·간격에 함께 적용됩니다. 과거 봉을 간격마다 1200개까지 미리 받아 계산하므로 값이 OKX·TradingView 와 같고, 화면 왼쪽 끝까지 선이 이어집니다.
- 그리기: `수평`(지지·저항선)은 한 번 클릭, `추세`는 두 점을 클릭합니다. 추세선은 오른쪽으로 연장됩니다.
- 가격 범위(`범위`): 두 점을 클릭하면 가격 차이·변동률·봉 수를 보여 줍니다.
- 롱·숏 포지션(`롱`·`숏`): 진입가를 한 번 클릭하면 목표(초록)·손절(빨강) 구간과 손익비가 생깁니다. 처음엔 손익비 2로 놓이고, 목표·손절선을 위아래로, 오른쪽 끝을 좌우로, 몸통을 끌어 통째로 옮깁니다. 손절선은 진입가를 넘어가지 않습니다.
- 수정·삭제: 그린 선·상자를 클릭하면 선택됩니다. 수평선은 위아래로 끌어 옮기고, 추세선은 끝점을 끌면 기울기가, 선을 끌면 위치가 바뀝니다. 선택한 채로 Backspace(또는 Delete)를 누르면 지워지고, Esc나 빈 곳 클릭으로 선택을 풉니다.
- 그리기 도구는 위쪽에 하나만 있고, 클릭한 칸의 종목에 그려집니다. 그린 선은 종목별로 저장되어 같은 종목을 보는 다른 칸(다른 봉 간격)에도 같이 보입니다.
- 종목 입력칸에 몇 글자만 치면 현물·무기한 선물 후보가 거래대금 순으로 뜹니다. `sox`를 치면 `SOXL-USDT-SWAP`이 나옵니다.
- `캡처` 버튼(또는 ⌘S)을 누르면 창 화면을 PNG로 바탕화면(`~/Desktop`)에 저장하고 클립보드에도 복사합니다. 옵시디언·노션에 바로 ⌘V로 붙여 넣을 수 있습니다. 파일 이름에 날짜·시각·종목이 들어갑니다.
- 보기 → 항상 위에 표시(⌘T)를 켜면 다른 창 위에 고정됩니다.
- 제목 표시줄 오른쪽 위 슬라이더를 왼쪽으로 끌면 창이 투명해집니다(최대 70% 투명). ⌥⌘- / ⌥⌘= 로 10%씩 조절할 수도 있습니다. 항상 위에 표시와 같이 쓰면 다른 창 위에 반투명하게 띄워 둘 수 있습니다.
- 상승은 빨강, 하락은 파랑이고 시간은 맥 시간대를 따릅니다.

로그인이나 API 키는 쓰지 않습니다. 시세를 읽기만 합니다.

## 빌드와 설치

macOS 13 이상과 Xcode Command Line Tools(`swiftc`)가 있으면 됩니다.

```sh
./build.sh           # build/OKX Mini Chart.app 생성
./build.sh install   # ~/Applications 에 복사
```

## 구성

| 경로 | 내용 |
|---|---|
| `web/index.html` | 차트 화면 전체. [Lightweight Charts](https://github.com/tradingview/lightweight-charts) 4.2.0을 CDN에서 불러옵니다 |
| `app/main.swift` | 창·메뉴·WKWebView를 띄우는 AppKit 코드 |
| `app/make-icon.sh` | `AppIcon.icns`를 다시 만들 때 씁니다 |
| `build.sh` | `.app` 번들을 만들고 ad-hoc 서명합니다 |

화면만 고칠 때는 `web/index.html`을 브라우저로 열어 확인한 뒤 `./build.sh install`로 다시 넣으면 됩니다.

## 쓰는 OKX API

- 과거 봉: `GET /api/v5/market/candles` 로 최근 300개, 이어서 `GET /api/v5/market/history-candles` 로 1200개까지 미리 받고, 왼쪽으로 스크롤하면 300개씩 더 받습니다
- 실시간 봉: `wss://ws.okx.com/ws/v5/business` 의 `candle1m`·`5m`·`15m`·`1H`·`4H`·`1D`
- 현재가·24시간 등락률: `GET /api/v5/market/ticker` (10초마다)
- 종목 검색: `GET /api/v5/market/tickers` (현물·무기한, 5분 캐시)
